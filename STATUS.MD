# KCC STATUS

THIS FILE IS THE SOLE CURRENT-STATE DOCUMENT FOR KCC.

## BUILD

THE HOST COMPILER BUILDS SUCCESSFULLY FROM THE CURRENT SOURCE WITH A C99 HOST
COMPILER.

THE HOST BUILD PRODUCES KCC FROM THE CC SOURCE MODULES IN THE PROJECT ROOT.

THE NATIVE BOOTSTRAP PROFILE USES HOST KCC TO COMPILE THE SAME SOURCE MODULES
FOR PDP-6/DAIMOS INTO VERSIONED BUILD-NATIVE-V1 ASSEMBLY AND DAS DOBJ FILES.
THIS IS AN OBJECT-BUILD GATE ONLY; A NATIVE KCC DXR IS NOT YET LINKED.

HOST_DAIMOS SELECTS DAIMOS PATH SYNTAX AND AVOIDS HISTORICAL TOPS-10/TOPS-20
UUO PROCESS/FILE SERVICES.  THE INITIAL PROFILE RETAINS COMPILE-ONLY DRIVER
BEHAVIOR UNTIL NATIVE DAS/DLINK INVOCATION IS ADDED.

THE NATIVE PROFILE ALSO OMITS DAIMOS-INAPPLICABLE TOPS RPG/TMPCOR CHAINING,
.UNV SYMBOL LOOKUP, HISTORICAL SOURCE-DEBUGGER/BLISS-PROFILER SUPPORT, AND
DEC MACRO/FAIL ASSEMBLER-HEADER GENERATION.  NATIVE OUTPUT IS DAS/GAS STYLE.
THIS DEAD-CODE PASS REDUCED THE 24 KCC OBJECTS FROM 139357 TO 134080 PDP-10
WORDS (TEXT+DATA+BSS), A SAVING OF 5277 WORDS, BEFORE LIBC AND THE USER
STACK ARE ADDED.

THE NATIVE BOOTSTRAP PROFILE THEN REDUCES ONLY NON-CAPACITY HASH BUCKET
ARRAYS (512 SYMBOL BUCKETS AND 509 TYPE BUCKETS) AND USES A 4096-CHARACTER
STRING-LITERAL POOL.  A HOST SELF-COMPILE PROBE PASSES WITH 512/509 HASH
BUCKETS; THE STRING-POOL FAILURE THRESHOLD LIES BETWEEN 2048 AND 2560
CHARACTERS, SO 4096 RETAINS SUBSTANTIAL MARGIN.  WITH THESE SETTINGS THE 24
NATIVE KCC OBJECTS TOTAL 125472 PDP-10 WORDS, 13885 WORDS BELOW THE ORIGINAL
PROFILE AND 5600 WORDS BELOW A 128K-WORD SELF-HOSTING CORE BEFORE THE USER
STACK AND LIBC ARE ADDED.

NATIVE SELF-HOSTING NOW USES TWO EXPLICIT COMPILER PHASES INSTEAD OF KEEPING
CCPP RESIDENT WITH THE PARSER/BACKEND:

- KCPP READS C SOURCE AND WRITES THE VERSIONED KPT4 COOKED-TOKEN STREAM.
- KCC1 READS KPT4 AND PRODUCES PDP-6 DAS/GAS ASSEMBLY WITHOUT LINKING CCPP.

KPT4 PRESERVES COOKED TOKEN SPELLINGS AND SOURCE LOCATION/PAGE STATE; PROCESS
LOCAL SYMBOL POINTERS ARE RECREATED BY KCC1.  THE HISTORICAL RA_EXPR
USAGE-BEFORE-INITIALIZATION STATE WAS MOVED FROM THE RAW PREPROCESSOR INTO
CCLEX SO IT NO LONGER CROSSES THE PROCESS BOUNDARY.

ALL 24 KCC TRANSLATION UNITS HAVE BEEN RUN THROUGH BOTH THE INTEGRATED
COMPILER AND KCPP -> KPT4 -> KCC1.  THE GENERATED PDP-6 ASSEMBLY IS
BYTE-IDENTICAL FOR ALL 24 UNITS.

THE FIRST SPLIT ATTEMPT STILL PULLED MOST OF THE BACKEND INTO KCPP THROUGH
COARSE OBJECT DEPENDENCIES.  KCPP NOW HAS PHASE-SPECIFIC CCDATA, CCERR,
CCOUT, AND CCSYM OBJECTS, PLUS A LOCAL PREPROCESSOR INTEGER-CONSTANT
EXPRESSION EVALUATOR FOR #IF/#ELIF.  THE CURRENT PDP-6 KCPP OBJECT CLOSURE IS
20176 TEXT + 750 DATA + 2190 BSS = 23116 WORDS BEFORE LIBC/STACK.  KCC1 IS
104435 TEXT + 1335 DATA + 5520 BSS = 111290 WORDS BEFORE LIBC/STACK.

HOST_DAIMOS NO LONGER PRETENDS TO BE THE HISTORICAL COMPUSERVE SYS_CSI
ENVIRONMENT.  DAIMOS RUNS WITH NO LEGACY SYS_* HOST PERSONALITY AND
CCSITE.H SELECTS DAIMOS PATHS PLUS TGSYS_NULL.  GENERIC KCC STATE THAT HAD
ACCUMULATED UNDER SYS_CSI GUARDS (REGISTER FIELDS, VLA/PACKED-POINTER FLAGS,
ABI NODE METADATA, AND NULL-POINTER-DIAGNOSTIC STATE) IS NOW COMMON, WHILE
ACTUAL CSI-ONLY IMUUO AND FOREIGN FORTRAN/BLISS/INTERRUPT LINKAGE IS OMITTED
FROM THE DAIMOS COMPILER.  THE CSI MUUO PAYLOAD WAS ALSO REMOVED FROM EACH
DAIMOS PEEPHOLE-BUFFER ENTRY.

DAIMOS FNAMESIZE IS 103 CHARACTERS INCLUDING NUL, MATCHING THE KERNEL
SYS_RUN_PATH_MAX_CHARS LIMIT OF 102 RATHER THAN INHERITING EITHER THE
HISTORICAL CSI 48-CHARACTER LIMIT OR THE 170-CHARACTER TOPS-20 FALLBACK.

AN INTEGRATED HOST_DAIMOS/NO-CSI COMPILER AND THE SPLIT
KCPP -> KPT4 -> KCC1 PIPELINE PRODUCE BYTE-IDENTICAL PDP-6 ASSEMBLY FOR ALL
24 KCC TRANSLATION UNITS.  THE PDP10-TESTKIT FAST SUITE PASSES THROUGH THE
FIRST SIX REGRESSIONS AND THEN STOPS AT THE PRE-EXISTING TESTKIT EXPECTATION
FOR THE OBSOLETE AGGREGATE LIB/KCC/PDP6RT.S RUNTIME FILE.

THE NATIVE TYPE-HASH OPTIMIZATION RETAINS MAXTYPE AS THE DYNAMIC TYPE
CAPACITY WHILE THASHSIZE IS ONLY THE HASH-BUCKET COUNT.  TYPEINIT CLEARS
THASHSIZE ENTRIES; USING MAXTYPE THERE OVERWROTE THE TRIMMED NATIVE TTABLE.

KCC'S HISTORICAL FNAMESIZE BUFFERS NOW REJECT UNREPRESENTABLE INPUT PATHS
BEFORE FNPARSE/ESTRCPY CAN OVERFLOW THEM.  THIS PRESERVES THE FIXED NATIVE
BUFFER SIZE INSTEAD OF GROWING RESIDENT STORAGE.

THE RUNTIME DIRECTORY CONTAINS PDP-6, KA10, AND KS10 HELPER ASSEMBLY FOR
ADJBP AND DOUBLE-WORD ARITHMETIC, PLUS COMMON ZEROING AND DIMODE DIVISION
HELPERS.

## TARGETS

THE CURRENT TARGET MODEL INCLUDES PDP-6, KA10, KI10, KL10, AND KS10.

THE PDP-6 TARGET PROVIDES THE EARLY-PROCESSOR-SAFE PORTABLE BASE.

THE KL10 SECTION-ZERO TARGET IS SUPPORTED BY THE NORMAL BUILD.  NON-ZERO
SECTION KL10 TARGETING REQUIRES MULTI_SECTION SUPPORT AT COMPILER BUILD TIME.

ITS TARGET VARIANTS ARE RESTRICTED TO SUPPORTED PROCESSOR COMBINATIONS.

## ABI

KCC USES THE CURRENT DAIMOS FOUR-ARGUMENT AND FOUR-RETURN-REGISTER PDP-10 C
ABI.

AC0 THROUGH AC7 ARE CALL-CLOBBERED.

THE FIRST FOUR ARGUMENT WORDS USE AC1 THROUGH AC4.  EXTRA ARGUMENT WORDS USE
THE STACK.

THE DAIMOS ENTRY CONTRACT PASSES ARGC IN AC1 AND ARGV IN AC2.

## CODE GENERATION

CURRENT CODE GENERATION INCLUDES TARGET-AWARE BYTE-POINTER STEPPING, PACKED
POINTER AND PACKED AGGREGATE STREAMING, DIMODE ASSIGNMENT AND ARITHMETIC
SUPPORT, AND EARLY-PROCESSOR FALLBACK HELPERS WHERE THE PDP-6 OR KA10 LACKS A
LATER INSTRUCTION.

PDP-6 AND KA10 FALLBACKS ARE USED WHERE LATER PROCESSORS CAN USE NATIVE
INSTRUCTIONS SUCH AS ADJBP OR DMOVEM.

GNU PACKED AGGREGATE VALUES OR EXPRESSIONS LARGER THAN TWO WORDS AT ARBITRARY
BIT OFFSETS ARE NOT YET SUPPORTED.  THESE CASES ARE REJECTED IN CCGEN2.C AND
ARE TRACKED IN TODO.MD.

## TESTING

COMPILER REGRESSION TESTS ARE MAINTAINED IN PDP10-TESTKIT.

KCC DOES NOT KEEP A DUPLICATE REGRESSION SUITE IN THIS SOURCE REPOSITORY.

ALL KCC TRANSLATION UNITS CURRENTLY SELF-COMPILE TO PDP-6 ASSEMBLY.  THE
NATIVE OBJECT GATES ASSEMBLE THE MONOLITHIC REGRESSION SET AND THE MINIMAL
KCPP/KCC1 PHASE SETS WITH DAS BEFORE ANY NATIVE-RUNTIME LINK IS ATTEMPTED.
