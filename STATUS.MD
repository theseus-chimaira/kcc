# KCC STATUS

THIS FILE IS THE SOLE CURRENT-STATE DOCUMENT FOR KCC.

## BUILD

THE HOST COMPILER BUILDS SUCCESSFULLY FROM THE CURRENT SOURCE WITH A C99 HOST
COMPILER.

THE HOST BUILD PRODUCES KCC FROM THE CC SOURCE MODULES IN THE PROJECT ROOT.

THE NATIVE BOOTSTRAP PROFILE USES HOST KCC TO COMPILE THE SAME SOURCE MODULES
FOR PDP-6/DAIMOS INTO VERSIONED BUILD-NATIVE-V1 ASSEMBLY AND DAS DOBJ FILES.
THIS IS AN OBJECT-BUILD GATE ONLY; A NATIVE KCC DXR IS NOT YET LINKED.

HOST_DAIMOS SELECTS DAIMOS PATH SYNTAX AND AVOIDS HISTORICAL TOPS-10/TOPS-20
UUO PROCESS/FILE SERVICES.  THE INITIAL PROFILE RETAINS COMPILE-ONLY DRIVER
BEHAVIOR UNTIL NATIVE DAS/DLINK INVOCATION IS ADDED.

THE RUNTIME DIRECTORY CONTAINS PDP-6, KA10, AND KS10 HELPER ASSEMBLY FOR
ADJBP AND DOUBLE-WORD ARITHMETIC, PLUS COMMON ZEROING AND DIMODE DIVISION
HELPERS.

## TARGETS

THE CURRENT TARGET MODEL INCLUDES PDP-6, KA10, KI10, KL10, AND KS10.

THE PDP-6 TARGET PROVIDES THE EARLY-PROCESSOR-SAFE PORTABLE BASE.

THE KL10 SECTION-ZERO TARGET IS SUPPORTED BY THE NORMAL BUILD.  NON-ZERO
SECTION KL10 TARGETING REQUIRES MULTI_SECTION SUPPORT AT COMPILER BUILD TIME.

ITS TARGET VARIANTS ARE RESTRICTED TO SUPPORTED PROCESSOR COMBINATIONS.

## ABI

KCC USES THE CURRENT DAIMOS FOUR-ARGUMENT AND FOUR-RETURN-REGISTER PDP-10 C
ABI.

AC0 THROUGH AC7 ARE CALL-CLOBBERED.

THE FIRST FOUR ARGUMENT WORDS USE AC1 THROUGH AC4.  EXTRA ARGUMENT WORDS USE
THE STACK.

THE DAIMOS ENTRY CONTRACT PASSES ARGC IN AC1 AND ARGV IN AC2.

## CODE GENERATION

CURRENT CODE GENERATION INCLUDES TARGET-AWARE BYTE-POINTER STEPPING, PACKED
POINTER AND PACKED AGGREGATE STREAMING, DIMODE ASSIGNMENT AND ARITHMETIC
SUPPORT, AND EARLY-PROCESSOR FALLBACK HELPERS WHERE THE PDP-6 OR KA10 LACKS A
LATER INSTRUCTION.

PDP-6 AND KA10 FALLBACKS ARE USED WHERE LATER PROCESSORS CAN USE NATIVE
INSTRUCTIONS SUCH AS ADJBP OR DMOVEM.

GNU PACKED AGGREGATE VALUES OR EXPRESSIONS LARGER THAN TWO WORDS AT ARBITRARY
BIT OFFSETS ARE NOT YET SUPPORTED.  THESE CASES ARE REJECTED IN CCGEN2.C AND
ARE TRACKED IN TODO.MD.

## TESTING

COMPILER REGRESSION TESTS ARE MAINTAINED IN PDP-C-TESTKIT.

KCC DOES NOT KEEP A DUPLICATE REGRESSION SUITE IN THIS SOURCE REPOSITORY.

ALL KCC TRANSLATION UNITS CURRENTLY SELF-COMPILE TO PDP-6 ASSEMBLY.  THE
NATIVE OBJECT GATE ASSEMBLES THOSE UNITS WITH DAS BEFORE ANY NATIVE-RUNTIME
LINK IS ATTEMPTED.
